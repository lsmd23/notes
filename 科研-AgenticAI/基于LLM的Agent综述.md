### 1. 必要的前置工作与背景
- **传统智能体的局限性**：早期的智能体研究通常聚焦于在孤立、受限的环境中训练策略函数（如通过强化学习） 。由于知识库有限且与人类学习过程脱节，这些智能体难以在开放域、无约束的环境中做出类似人类的决策 。
- **大语言模型的崛起**：近年来，大语言模型（LLMs）凭借庞大的参数量以及在海量网络文本上的预训练，展现出了通往通用人工智能（AGI）的潜力 。
- **转移契机**：研究者开始尝试将 LLM 作为大范围智能体的“中央大脑”（控制器），为其配置记忆、规划等模块，使其能够像人类一样自主感知环境并执行行动 。
### 2. 论文解决的核心问题
本篇综述从全局视角对基于 LLM 的自主智能体进行了系统性梳理，填补了此前缺乏宏观对比与总结的空白 。文章主要围绕以下三大核心维度展开：
1. **智能体构建（Construction）**：如何设计合理的架构以最大化释放 LLM 的潜能，以及智能体如何获取完成特定任务的能力 。
2. **智能体应用（Application）**：梳理智能体在社会科学、自然科学和工程学三大领域的落地现状 。
3. **智能体评估（Evaluation）**：总结当前对智能体能力进行主客观评估的策略与基准 。

### 4. 关键数学推导：记忆读取机制
在记忆操作中，智能体需要从记忆库 $M$ 中提取最有价值的信息来辅助当前行动 。论文将现有文献中的记忆提取标准归纳为统一的形式化方程 ：$$n^{*}=\arg\max_{m\in M}(\alpha s^{rec}(q,m)+\beta s^{rel}(q,m)+\gamma s^{imp}(m))$$
其中各项变量与函数的物理含义如下 ：
- $q$：当前的查询（Query），例如智能体当前面对的任务或所处的上下文环境。
- $M$：智能体拥有的所有记忆条目的集合。
- $m$：记忆集合 $M$ 中的某一个特定记忆条目。
- $s^{rec}(\cdot)$：**近年性（Recency）评分函数**，用于衡量记忆 $m$ 发生时间的远近，时间越近得分越高。
- $s^{rel}(\cdot)$：**相关性（Relevance）评分函数**，用于衡量查询 $q$ 与记忆 $m$ 之间的语义相关度（通常通过计算向量嵌入的余弦相似度实现）。
- $s^{imp}(\cdot)$：**重要性（Importance）评分函数**，用于衡量记忆 $m$ 自身性质的独立重要程度（与查询 $q$ 无关）。
- $\alpha, \beta, \gamma$：平衡参数。通过调整这些权重可获得不同的记忆读取策略（例如令 $\alpha=\gamma=0$ 则退化为纯相关性检索）。
### 5. 实验结果、启示与挑战
综述总结了大量实证研究（如 Generative Agents、Voyager 等），并提炼出以下核心启示与技术挑战：
- **能力获取的范式转移**：从传统机器学习的“参数学习”，过渡到大模型时代的“提示词工程”，并进一步演进到智能体时代的“机制工程”（如设计试错机制、群体协同、经验累积与自主演化） 。
- **社会科学仿真红利**：通过给 LLM 智能体赋予特定 Profile，能低成本高效模拟人类心理学实验和群体意见走向，且大模型在特定实验中展现出极高的仿真对齐度 。
- **关键挑战**：
    - _幻觉问题（Hallucination）_：智能体在长期规划或代码生成中可能生成看似合理实则错误的虚假信息，带来安全隐患 。
    - _知识边界（Knowledge Boundary）_：LLM 内部拥有的上帝视角海量知识，往往会污染其对“有限理性人类”的真实行为模拟 。
    - _效率瓶颈（Efficiency）_：由于自回归生成的特质，智能体在完成单次行动前需反复读写记忆并进行多轮规划质询，导致决策链路耗时较长 。
